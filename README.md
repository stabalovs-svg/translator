# Голосовой переводчик RU ⇄ EN (бесплатная версия)

Веб-приложение (PWA) для телефона: вы говорите по-русски, оно озвучивает по-английски, и наоборот.
Используются встроенные функции телефона: распознавание речи (Web Speech API) и синтез речи (speechSynthesis).
Перевод выполняет бесплатный сервис MyMemory (без ключа, есть дневной лимит).

## Деплой
1. Загрузите папку в репозиторий GitHub и импортируйте его в Vercel (Framework Preset: Other, Output Directory: `.`).
   Нужен HTTPS (Vercel даёт его автоматически), иначе браузер не даст доступ к микрофону.
2. Откройте ссылку на телефоне.

## Установка на телефон
- Android (Chrome): меню ⋮ → «Установить приложение» / «Добавить на главный экран».
- iPhone (Safari): «Поделиться» → «На экран Домой». Но на iPhone распознавание речи надёжнее работает
  в обычной вкладке Safari, чем из иконки на экране; из иконки можно пользоваться вводом текста (диктовка клавиатурой).

## Заметки
- Нужен интернет.
- Качество голоса зависит от телефона (на iPhone загрузите «улучшенные» голоса в настройках).
- Без ключей и серверов. Позже можно заменить MyMemory на Claude/DeepL, а распознавание на облачное (Whisper) для автоопределения языка.
